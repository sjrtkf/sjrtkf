새 도우미를 실행하면 같은 확장 폴더에 업데이트합니다. 최초 한 번 연결한 뒤에는 자동으로 다시 연결합니다. 업데이트 후 예매 탭은 새로고침해 주세요.

처음 한 번 · 고정 폴더 등록 순서
  1. Chrome에 확장 등록
    위 버튼으로 폴더를 열고, Chrome 주소창에 chrome://extensions를 입력하세요. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드에서 이 폴더를 선택하세요.
  2. 연결 코드 복사
    위의 연결 코드를 복사하세요.
  3. Chrome에서 연결
    Chrome의 퍼즐 아이콘 → 도우미 확장에 코드를 붙여넣고 프로그램 연결을 누르세요.

    몇 자리, 어떤 조건으로?

    저장됨

    체크를 끄면 여러 구역·등급의 좌석을 합칩니다. 높은 순위의 좌석을 최대한 포함하고, 부족한 수만 다음 순위에서 채웁니다.

    사이트가 시야방해석으로 표시한 좌석을 제외합니다. 실제 시야를 보장하는 조건은 아닙니다.

    해당 좌석의 이용 자격을 확인한 경우에만 포함하세요. ‘104블록 W4-1’ 같은 특수 표기의 확인된 1인석은 1매만 지원하며, 숫자 열 범위가 있는 순위에서는 제외됩니다.

    매수·연석·시야방해석 및 장애인·휠체어석 설정은 유지합니다. 우선순위를 비워 두면 처음부터 전체 구역에서 찾습니다.

    2석 · 연석 필수 · 시야방해석 제외 · 장애인·휠체어석 제외

    전체 구역 · 3루·중앙 → 가까운 구역 표기 → 앞열 → 통로 거리

    우선순위 구역·블록
    여러 조건을 순서대로 적용하기

    조건 묶음을 사용하지 않으면 기본 우선 구역·블록부터 찾습니다.

    통로는 좌석 배치로 추정하므로 벽 쪽 끝자리와 구분되지 않을 수 있습니다. 빈 구역·블럭·열은 제한 없음입니다.

    문자 열은 A=1, B=2, …, Z=26으로 입력합니다. 실제 화면의 열 표기를 확인하세요.

    기본 우선 구역·블록

    기본 선호: 3루·중앙 구역 → 가까운 구역 표기 → 앞열 → 통로 거리. 구역 이름의 필드·그라운드·익사이팅·덕아웃, 내야 표기를 참고합니다. 실제 거리와 통로 여부를 보장하지 않습니다.

    조건 묶음을 모두 끄면 적용됩니다. 입력한 구역·블록을 먼저 찾고, 전체 구역 찾기를 켜면 다음으로 범위를 넓힙니다. 이름·코드는 정확히 일치해야 하며 띄어쓰기는 무시합니다.

    저장한 조건을 다음 실행에서도 사용합니다.

      서버 시계 · 확인 전

      아직 사이트의 시계를 읽지 않았다는 뜻입니다. 예매 시작 일정과는 별개이며 오류가 아닙니다.

      공식 일반 예매 시각을 자동으로 채웁니다. 판매 시작이 지난 경기도 확인된 원래 시각과 출처를 표시합니다. 입력값은 직접 수정할 수 있습니다.

      예약 기준 시각을 −250~+250ms 보정합니다. 보정 시각이 되어도 사이트가 활성화되기 전에는 요청하지 않습니다.

      목록에서는 선택한 경기의 활성화를 기다린 뒤 한 번 진입합니다. 준비 화면에서는 사이트 함수가 요청 없이 종료한 경우만 1초 후 재확인합니다(최대 3회 실행). 요청이 발생하면 응답이 늦어도 추가 전송하지 않습니다. 미개방·제한·결과 불명은 원인을 기록하고 중지합니다.

      준비·대기열 진입부터 구역·보안문자·팝업·좌석·가격 선택까지 HTTP 또는 사이트 함수로 처리합니다. 예매 동작에 마우스 클릭이나 입력 이벤트를 보내지 않습니다.
